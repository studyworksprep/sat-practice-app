## How suitability was assessed

Matches followed each technique’s actual description and process, using the question’s task, passage or mathematical constraints, complete answer choices, and rationale where needed. Skill codes helped organize the review, but were not treated as automatic technique tags. A usable alternative solution was sufficient; the technique did not need to be the shortest solution.

Ambiguous graph, parameter, model, and geometry cases received explicit content decisions. Numerical testing preserved dependent variables and all fixed constraints. Regression methods retained the required model form and checked domain restrictions. Questions that merely mentioned a relevant topic were skipped when the requested reasoning did not fit the technique.

The narrow he/they shortcut was checked against all four complete verb choices: a genuine three-to-one number split, an answer key selecting the minority, and subject agreement supported by the passage. All 52 reviewed matches passed those checks. Opening-modifier questions were also selected through content review rather than tagging every grammar question.

## Verification

The 32 append-only transactions checked question fingerprints, original tag sets, publication eligibility, technique definitions, and default skill mappings before writing. Replay guards made a completed batch safe to retry. The final comparison verified all 3,415 intended additions, every original tag record, every active question record, and the exact expected tag set for every question. No question content, answers, metadata, technique definitions, or default mappings changed. The seven skipped questions retained their original tags.
